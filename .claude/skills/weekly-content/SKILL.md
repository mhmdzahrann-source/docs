# Weekly content loop for Khayal

1. **Analyse:** use the `analyst` agent for the last 7–30 days and report what worked.
2. **Research:** use the `researcher` agent for current trends and ideas.
3. **Plan:** make a 7-day calendar table (day, channel, format, pillar, topic) that follows the posting rhythm in the `publisher` agent and the pillars in `marketing/BRAND.md`. Show it to the owner and wait for OK.
4. **Write:** use the `content-writer` agent to draft every post in the approved plan.
5. **Create:** use the `creative` agent only for posts that need graphics or voiceovers (ask before spending credits on video).
6. **Queue:** use the `publisher` agent to put everything into Metricool **for review**.
7. **Summary:** give the owner one table of everything waiting for approval, plus a list of what to film at the stable this week.

Nothing goes live without the owner's approval.
